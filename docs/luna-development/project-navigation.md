# Project navigation from source structure

Broad project file requests now return grounded NAS project/business-development locations, linked Notion documents, key material types and report/review points. An elliptical detail follow-up resolves the latest project and performs retrieval again. A named new topic or unrelated intervening question stops that continuation.

The common policy operates on source-backed roots and bounded candidates. It collapses nested files under dated workflow folders, retains separately dated reports in flat folders, and expands within the important report's phase/section before moving elsewhere. Explicit importance marks retain priority. Comparable project-level planning/document design is preferred to a later component design. Administrative folder purpose, received/reference samples and numbered old/backup folders cannot become core design merely because the filename contains design words.

Date/folder adjacency is a navigation candidate, not evidence of a causal decision chain, approval or complete body reading. The response states this and does not claim full inventory coverage. Candidate/omitted step counts and retrieval limits remain visible in metadata.

## Data separation

- Primary file rows, folder records and manual marks remain unchanged.
- General rules live in versioned code (`project-navigation/1`, `document-role/4`).
- Per-answer `important_materials.navigation` is derived layer-2 evidence with rule version, source row/scan/modified identifiers, scope anchor and selected paths. It does not activate inferred project memberships or mutate verified knowledge.
- Existing saved document profiles with older role policies become stale under the existing freshness check; this release does not regenerate them or run a bulk job.
- No new layer-3 content comparison or document summary is asserted by this metadata-only flow.

Tests cover continued retrieval, topic switching, phase-local chronology, folder grouping, cost/design conflicts, invalid dates, manual priority and evidence preservation. Real source snapshots and before/after answers are kept privately, never in public fixtures.
