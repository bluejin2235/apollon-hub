# PPTX 본문 추출 무결성 — 2026-09-25

회사 PC의 약 321MB PPTX 읽기 성공 보고 후 실제 추출 경로를 검토했다. 기존 extractPptxYauzl은 압축파일 전체/미디어를 메모리로 읽는 대신 슬라이드와 노트 XML만 읽는다. 따라서 파일 크기만으로 추출 불가를 단정하지 않는다. 실제 사용자 샘플은 아직 파싱하지 않았다.

## 재현한 결함

- 첫 슬라이드 성공 후 다음 XML의 openReadStream 콜백이 실패하면 오류를 버리고 진행해 부분 본문이 status=ok가 됐다.
- ZIP 자체가 오류를 내고 열려 있는 스트림이 끝나지 않으면 pending이 줄지 않아 완료되지 않을 수 있었다.
- 스트림 오류 후에도 다음 항목을 읽었고 즉시 자원을 정리하지 않았다.

## 수정과 검증

XML 열기/읽기 또는 ZIP 오류는 즉시 전체 추출 실패로 처리한다. 활성 스트림과 ZIP을 닫고, 뒤늦은 콜백은 결과를 바꾸지 못한다. 추출 시작 전에 이벤트 수신기를 등록한다. 정상 파일은 기존처럼 슬라이드/노트 본문만 반환한다.

tests/luna/nas-pptx-extraction.test.cjs는 네 종류의 오류를 주입해 부분 본문이 정상으로 반환되지 않는지, 자원이 정리되는지 검증한다. 별도 실제 ZIP 파일로 슬라이드/노트가 추출되고 미디어는 열지 않는지 확인한다. 수정 전에는 오류 재현 4건이 실패/시간 초과했고 수정 후 5건 모두 통과했다.

## 범위와 남은 항목

운영 DB, 회사 PC 파일과 작업 스케줄러는 변경하지 않는다. 과거에 부분 추출된 파일을 식별하거나 자동 재색인하지 않는다. 실제 대형 샘플의 파싱 시간/메모리, XML 텍스트 해석 완전성, 기존 실패 파일 재시도 정책, 청크 교체의 원자성은 별도 검증/개선 대상이다. 이번 수정은 과거 DB 자료가 완전하다는 증거가 아니다.
