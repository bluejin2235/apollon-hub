D안 · 모달 → 페이지 (A + B)

한두 장 확인은 모달로, 계속 따라갈 땐 페이지로.

1  대화에서 썸네일 클릭  →  모달 (A안)
     큰 이미지 · 전체 경로 복사 · 칩 · 관련 이미지 한 줄
     여기서 끝나는 경우가 대부분

2  [🔍 이미지로 더 탐색하기]  →  전용 페이지 (B안)
     넓은 화면 · 관련 이미지 24장 · 칩으로 좁혀가기
     계속 따라가며 훑을 때

3  [← 대화로 돌아가기]  →  원래 자리로
D안을 권합니다.

「때에 따라 다르다」고 하셨는데, 실제로 그렇습니다. 한두 장 확인하고 경로만 복사하는 경우가 대부분이고, 그때 페이지를 전환하면 오히려 번거롭습니다.

구글도 같은 구조입니다. 검색 결과에서 이미지를 누르면 라이트박스(모달)가 뜨고, 더 보려면 이미지 탭으로 넘어갑니다.

개발도 나눌 수 있습니다. 모달을 먼저 만들어 써보고, 전용 페이지가 필요하면 그때 붙이면 됩니다.
