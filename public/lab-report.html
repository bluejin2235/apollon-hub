완료한 작업과 남은 작업

  • 완료: 운영과 분리된 시험 브랜치·URL, 동일 질문·세 단계 판정 화면, 실제 차단 기록, 공식 Custom Agent REST 호출 코드, 개발 기록. 로컬 빌드와 판정 로직 점검 통과.
  • 완료: 페이지 접근이 없는 전용 시험 에이전트 생성. 웹 검색·자동 언급 실행은 끄고 예약 실행은 만들지 않음. 기존 업무 에이전트 설정은 변경하지 않음.
  • 개발자가 이어서 해야 할 일: A 브라우저 실행기, C MCP 수신기, 인증 연결, 검색 범위 검증, 실제 같은 질문의 연속 실행, 원문·출처 대조.
  • 사용자 승인이 필요한 일: 전용 시험 에이전트에 지정한 Working 페이지 트리의 읽기 접근 부여, 전용 API 연결 생성·안전한 인증 등록. 브라우저 조작 규칙상 민감 자료에 대한 새로운 앱 접근은 실행 시점 확인이 필요.
  • A·C 추가 조건: 루나 서버가 호출할 브라우저 환경과 그 환경의 사용자별 Notion 로그인. ChatGPT의 현재 브라우저 로그인만으로 루나가 자동 실행할 수는 없음.

개인정보 차단은 에이전트 지시문만으로 입증되지 않습니다. 허용 페이지 범위, 사용자 격리, Private 자료의 검색 차단을 실제로 확인한 뒤 판단해야 합니다.

다음 실행의 통과 기준

  1. 시험 URL에서 친 질문과 연결된 노션 세션의 사용자 메시지가 정확히 한 번, 동일한 내용으로 확인됨.
  2. 그 세션의 AI가 완료되고 원문과 출처를 보존함.
  3. 자동으로 받은 루나 수신본을 원문·출처와 대조해 누락이 없음을 확인함.

세 단계가 모두 확인되기 전에는 개발 가능성 검증 완료 또는 운영 적용 완료로 보고하지 않습니다. 1회 성공 이후에도 평균 시간·동시 사용·권한 철회 등은 별도 반복 검증이 필요합니다.
